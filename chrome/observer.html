Concepts

Actors are tools and runtimes observed by the Harness. Task is the current goal. Run is a durable execution instance. Span is one causally scoped operation. Unified timeline is the raw evidence stream.

Attribution links evidence to a ChatGPT conversation/turn. browser_inferred means the identity was conservatively inferred from one active browser turn; it is not authoritative transport identity.

Controls

Settings manages explicit Browser Bridge page sharing. Update appears only when the loaded extension differs from disk. Open source chat navigates from scoped evidence to its owning ChatGPT conversation.
