Execution Delivery Harness Browser Bridge

Connect your local companion, then choose each page to share from the toolbar button.

  1. Install Node.js 22 or later and the open-source companion.
  2. Run npm start in the project folder.
  3. Paste its extension pairing token below. Never paste it into a chat or public page.

Companion address: http://127.0.0.1:43119

What is shared

Only normal pages you explicitly share. Access expires after 30 minutes and is revoked by navigation, reload, closing the tab or restarting the extension. This version reads text; it does not send messages or submit applications.

There is no telemetry or dzzk hosted service. Page text is processed in memory by your companion and sent to the MCP client you authorize. That client's data policy applies.
